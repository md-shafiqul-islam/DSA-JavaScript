# Data Structures and Algorithms with JavaScript

This repository documents my journey of learning Data Structures and Algorithms (DSA) using JavaScript.

## Goals

- Build strong problem-solving skills.
- Understand time and space complexity.
- Learn common data structures and algorithms.
- Practice coding interview problems.
- Improve my ability to write efficient and clean code.
- Prepare for Software Engineer interviews.

## First DSA Skill

Before analyzing an algorithm, ask:

1. **How many times does the main operation run?**
2. **Does it grow as `n` grows?**
3. **Does it use extra memory as `n` grows?**
