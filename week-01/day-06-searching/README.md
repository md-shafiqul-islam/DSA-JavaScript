## Topics Covered

- Searching fundamentals
- Linear Search

- Sorted vs unsorted data

- Binary search space reduction
- Search Insert Position
- Time and space complexity

## Key Patterns

### Linear Search

Check elements one by one until the target is found.

- Works with sorted or unsorted data.
- Time: `O(n)`
- Space: `O(1)`

### Binary Search

Repeatedly divide a sorted search space into two halves.

- Requires sorted/ordered data.
- Time: `O(log n)`
- Space: `O(1)`
